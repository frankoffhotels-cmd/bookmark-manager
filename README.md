# Bookmark Manager

Chrome extension for managing bookmarks with tags, search, and a modern UI.

## Tech stack

- HTML
- CSS
- JavaScript
- Chrome Extensions API (Manifest V3)

## Features

- View Chrome bookmarks as tiles in a two-column grid.
- Add and edit tags for each bookmark.
- Search bookmarks by title and tags.
- Filter bookmarks by tag.

## Installation

1. Clone or download this repository.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the `bookmark-manager` folder.
5. Click the extension icon to open the bookmark manager.
